Every fact is a symbol. A change creates a new version instead of overwriting, so deadline.1 stays in the history and is marked as killed by deadline.2. The verdict column is the reachability pass for the selected rule. Click a version to see the sentence that defined it.

Scope tree and the active chain

Task phases become nested scopes, like blocks in a program. At the end of the transcript, the open scopes form the active chain. That chain is the root set for reachability: facts declared in closed scopes die unless they were used from the active chain.
